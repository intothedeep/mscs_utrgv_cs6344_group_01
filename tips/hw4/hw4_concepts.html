Step 1 of 13

분할표(contingency table)

목적
두 범주형 변수(categorical variable) 사이의 관계를 파악한다.
예
두 버전의 시스템 v1, v2가 같은 사건(event)을 예측한다. 괄호 안은 독립일 때의 기대도수(expected count)다.
v2: Yesv2: No합계(total)
v1: Yes40 (22.5)10 (27.5)50
v1: No5 (22.5)45 (27.5)50
합계(total)4555100

설명용 값(Illustrative values): 예시 숫자다. HW4 데이터가 아니다.

읽는 법
40개: 둘 다 Yes. 45개: 둘 다 No.
10개: v1만 Yes. 5개: v2만 Yes.
왜 중요
두 버전이 얼마나 일치하는지 본다. 여기서는 100개 중 85개(85%)가 일치한다.
카이제곱(χ²) 독립성 검정, 자카드 지수(Jaccard index) 같은 분석의 기초 자료다.
주의
v1과 v2가 같은 관측 대상에서 나왔다면 단순한 독립성 검정은 맞지 않을 수 있다.
그때는 목적에 따라 맥니마 검정(McNemar test: 짝지은 이진 결과의 불일치 검정)이 맞을 수 있다.
Step 2 of 13

상호정보량(mutual information, MI)

목적
한 변수를 알 때 다른 변수의 불확실성이 얼마나 줄어드는지 잰다.
예
v1의 예측을 알면 v2의 예측을 얼마나 잘 맞히나?
어떻게
MI = H(v1) + H(v2) − H(v1, v2). H는 엔트로피(entropy), 곧 모름의 양이다.
H(v1) = 1.0000 bits, H(v2) = 0.9928 bits각 변수의 모름
H(v1, v2) = 1.5955 bits네 칸 전체의 모름
MI = 1.0000 + 0.9928 − 1.5955 = 0.3973 bitsv2의 모름 중 40%가 줄어든다

설명용 값(Illustrative values): 예시 숫자다. HW4 데이터가 아니다.

특징
범주형 변수에 쓴다.
선형(linear)이 아닌 관계도 잡는다.
MI = 0이면 독립이다. 이것은 모집단(population) 기준이다.
표본(sample)에서 추정한 MI는 독립이어도 0보다 클 수 있다.
왜 중요
같은 결과를 내는지를 넘어, 두 결과가 정보를 얼마나 공유하는지 본다.
Step 3 of 13

자카드 지수(Jaccard index, J)

목적
두 집합(set)이 얼마나 겹치는지 잰다.
예
v1이 Yes로 예측한 항목: {A, B, C, D}. v2: {B, C, D, E}.
교집합(intersection) = {B, C, D}크기 3
합집합(union) = {A, B, C, D, E}크기 5
J(A, B) = |A ∩ B| ÷ |A ∪ B| = 3 ÷ 5 = 0.60과 1 사이

설명용 값(Illustrative values): 예시 숫자다. HW4 데이터가 아니다.

읽는 법
J = 1이면 두 집합이 같다. J = 0이면 교집합이 없다.
왜 중요
두 버전이 같은 항목을 얼마나 많이 골랐는지 비교한다.
쓰는 곳
두 모델이 탐지한 객체(object) 비교
두 버전이 고른 특징(feature) 비교
두 시스템이 찾은 사건(event) 비교
Step 4 of 13

카이제곱 검정(chi-squared test, χ²)

목적
관측 빈도가 가설에서 기대하는 빈도와 얼마나 다른지 평가한다.
가정
Step 1의 분할표에서 v1과 v2가 독립이라고 둔다.
어떻게
기대도수(expected count) Eij = 행 합계 × 열 합계 ÷ N.
E11 = 50 × 45 ÷ 100 = 22.5독립이면 둘 다 Yes는 22.5개
O11 = 40기대보다 훨씬 크다
χ² = Σ (O − E)² ÷ E = 49.49, 자유도(degrees of freedom, df) 1p = 2.0e-12

설명용 값(Illustrative values): 예시 숫자다. HW4 데이터가 아니다.

이름무엇이 예의 값
카이제곱 통계량(chi-squared statistic)관측과 기대의 차이를 모은 숫자 하나49.49
카이제곱 분포(chi-squared distribution)H0가 맞을 때 그 숫자가 나오는 분포자유도 1
카이제곱 검정(chi-squared test)위 둘로 p값을 구하고 판정하는 절차p = 2.0e-12, H0 기각
구분
같은 것의 두 부분이다. 통계량은 숫자 하나, 검정은 그 숫자로 결론까지 가는 절차다.
왜 중요
두 변수 사이에 통계적으로 유의한 연관이 있는지 검정한다.
주의
같은 대상의 v1과 v2를 비교하면 관측값이 짝지어져 있다.
이때는 일반 χ² 독립성 검정의 가정을 먼저 확인한다(Step 1의 맥니마 검정 참고).

피어슨 상관계수(Pearson correlation, r) = Cov(X, Y) ÷ (σX σY)공분산(covariance) ÷ 표준편차(standard deviation)의 곱

Step 7 of 13

p값(p-value, 유의확률)

목적
H0가 참일 때, 관측 결과 또는 더 극단적인 결과가 나올 확률이다.
예: H0
귀무가설(null hypothesis, H0): v1과 v2의 평균 성능 차이는 0이다.
예: H1
대립가설(alternative hypothesis, H1): 평균 성능 차이는 0이 아니다.
뜻
p = 0.03이면, H0가 참일 때 이만큼 또는 더 극단적인 결과가 나올 확률이 3%다.
p = 0.03 < 유의수준(significance level) α = 0.05귀무가설(H0)을 기각한다

설명용 값(Illustrative values): 예시 숫자다. HW4 데이터가 아니다.

왜 중요
관측된 차이가 우연한 표본 변동만으로 설명되기 어려운지 본다.
아닌 것
p < 0.05는 "H0가 참일 확률이 5%"라는 뜻이 아니다.
"v2가 v1보다 실제로 낫다"는 뜻도 아니다.
"결과가 재현될 확률이 95%"라는 뜻도 아니다.
함께 볼 것
효과 크기(effect size), 신뢰구간(confidence interval), 표본 크기(sample size)

문제 2: p값(p-value)

목적
"선형 상관이 없다"는 귀무가설(null hypothesis, H0)을 검정한다.
가설
H0: ρ = 0. 대립가설(alternative hypothesis, H1): ρ ≠ 0. ρ(rho) = 모집단(population)의 피어슨 상관계수.
어떻게
t = r √(n − 2) ÷ √(1 − r²), 자유도(degrees of freedom, df) = n − 2. 양측(two-sided) p값을 구한다.
판정
α = 0.05. p < 0.05면 H0 기각. p ≥ 0.05면 기각할 증거가 부족하다.
데이터셋r (예)|r|p (계산)결론
p2a+0.80.8< 0.001유의함
p2b-0.30.30.0015유의함
p2c+0.10.1< 0.001유의함

설명용 값(Illustrative values): 예시 숫자다. HW4 데이터가 아니다.

읽는 법
p2b는 r이 음수지만 유의하다. 유의성은 방향과 관계없다.
p가 작다는 것만으로 상관이 강하다고 말할 수 없다.
고친 점
원래 예시는 p2c의 p를 0.15로 두었다. 그러나 n = 2,100이면 r = 0.1도 p = 4.4e-06로 유의하다. 표의 p는 r과 n에서 계산한 값이다.
곧 n이 크면 약한 상관도 유의하게 나온다. Step 12의 핵심과 같다.

from pathlib import Path
import matplotlib.pyplot as plt
import pandas as pd
from scipy.stats import pearsonr

DATASETS = ("p2a", "p2b", "p2c")
ALPHA = 0.05


def analyze_dataset(path: Path) -> dict[str, float | int | str]:
    data = pd.read_csv(path)
    if data.shape[1] != 2:
        raise ValueError(f"{path}: expected exactly two columns")
    if data.isna().any().any():
        raise ValueError(f"{path}: missing values found")
    if not all(pd.api.types.is_numeric_dtype(data[c]) for c in data.columns):
        raise ValueError(f"{path}: both columns must be numeric")
    if not data.map(lambda x: pd.notna(x) and abs(x) != float("inf")).all().all():
        raise ValueError(f"{path}: non-finite values found")
    if len(data) < 3:
        raise ValueError(f"{path}: at least three samples are required")
    x, y = data.iloc[:, 0], data.iloc[:, 1]
    if x.nunique() < 2 or y.nunique() < 2:
        raise ValueError(f"{path}: both variables must vary")
    r, p = pearsonr(x, y)
    return {"dataset": path.stem, "n": len(data), "r": r, "p_value": p, "significant": p < ALPHA}


def plot_dataset(path: Path, ax: plt.Axes) -> None:
    data = pd.read_csv(path)
    ax.scatter(data.iloc[:, 0], data.iloc[:, 1], alpha=0.6)
    ax.set_xlabel(data.columns[0])
    ax.set_ylabel(data.columns[1])
    ax.set_title(path.stem)
    ax.grid(True)


def main() -> None:
    paths = [Path(f"{name}.csv") for name in DATASETS]
    results = pd.DataFrame([analyze_dataset(path) for path in paths])
    print(results.to_string(index=False))
    results["abs_r"] = results["r"].abs()
    print("\nAssociation strength ranking:")
    print(results.sort_values("abs_r", ascending=False)[["dataset", "r", "abs_r"]].to_string(index=False))
    print("\nP-value ranking:")
    print(results.sort_values("p_value")[["dataset", "p_value"]].to_string(index=False))
    fig, axes = plt.subplots(1, 3, figsize=(15, 4))
    for path, ax in zip(paths, axes):
        plot_dataset(path, ax)
    fig.tight_layout()
    plt.show()


if __name__ == "__main__":
    main()
