Narrow sample

Only 47,948 of 688,131 markets (7.0%) pass the filters.

No true event key

Markets on one event move together, so the p-values are optimistic.

One day before close

Speaker: Intro (Taek Lim). About 45 seconds. We want to be clear about what this study cannot say. We keep only 7.0% of the markets, so the result holds for markets that pass our filters. The data has no true event key, so markets on the same event move together and our p-values are optimistic. Trading continues after the scheduled close, when the answer may be known, so we price one day before the close. That choice rests on a one-month pilot. Finally, a wallet is an address and not a person, and one pre-registered rule was changed after we saw a result, which we report as an amendment. Future work follows from these limits. First, build a true event key, measure how markets on one event move together, and test Q1 with markets grouped by event. Second, Q2 shows a concentrated crowd, but we do not link it to Q1. Volume counts money, not people, so test whether the gap depends on the number of distinct wallets, holding volume fixed. Third, correct the prices after the fact and test that correction on later markets.
