Source: course report Appendix C and D; paper Appendix G
Speaker: Q1 speaker. About 1 minute 15 seconds. Why: reviewers asked whether our choices create the gap, so we ran six checks. How: each new row sits next to the original Q1 result and does not replace it. Result: changing the price rule gives a net gap of minus 1.20%. Looking only at Yes/No markets gives minus 1.32%. The key one is M3. Markets on one event move together, so we group them with a proxy event key, and the cluster bootstrap interval from minus 1.41% to minus 0.58% still lies below zero. M4 and M5 describe the kept markets and the size of the gap. Last, R2 uses the last price before the close instead of the price one day before. The chi-square is 53.6 and still rejects, and the net gap shrinks to minus 0.65%. So the last day of news explains part of the gap, not all of it. Meaning: the gap does not come from one choice we made. Two backup slides show M1, M2 and M4 in more detail.
