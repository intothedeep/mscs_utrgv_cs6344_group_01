Backup. Speaker: Intro (Taek Lim). About 45 seconds. Why: someone may ask which method answers which question. How: each row names one method, the question it answers, and where we use it. Result: Q1 uses one price, a chi-square test for the whole verdict, an exact binomial test per bin, BH and Bonferroni corrections for the ten bin tests, a 95% z interval for the error bars, the review checks and the volume groups. Q2 uses top shares, the CCDF and a Welch t test on log volume. Q3 uses the mean, the median and the QQ plot. Meaning: every number in the talk comes from one of these rows.
