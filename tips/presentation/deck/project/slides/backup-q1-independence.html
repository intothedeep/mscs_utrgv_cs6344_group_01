Backup, Q1 speaker. About 45 seconds. Why: our tests assume the markets are independent, and someone may ask what happens if they are not. How: the gap itself does not change, because the counting is the same. What changes is the spread. Markets on one election move together. If the candidate loses, twenty markets fall to zero at once, more like one big coin than twenty coins. So the real variance of a count is larger than we assumed. Then our z and chi-square come out too large, the p-values too small, and the intervals too narrow. We would be more sure than we should be. To check, we resampled whole events instead of single markets, using a proxy event key. The net-gap interval got about 1.4 times wider, from a width of 0.58 to about 0.8 points, but it still lies fully below zero. So the conclusion that prices run a little high stands. Limits: the event key is a proxy, so the real interval may be wider. We did not redo the per-bin p-values, so those may be too small. And markets where only one outcome can win are negatively correlated, which works the other way. We did not measure that.
