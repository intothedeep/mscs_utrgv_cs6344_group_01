    편집 방법 세 가지 비교Compare the three ways to edit

    왜: 방법마다 고친 내용이 흐르는 길이 다르다. 길을 모르고 고치면 두 판이 어긋난다.Why: Each way sends your change along a different path. Edit without knowing the path and two versions drift apart.

    #방법Way누구에게 맞나Best for고친 내용이 다른 판으로 가나Does the edit reach the other copies왜 이렇게 정했나Why
    AA 온라인 덱 (권장)A Online deck (recommended)모든 팀원Every teammate온라인 덱에 바로 저장된다. 저장소로는 소유자가 가져온다.Saved in the online deck at once. The owner pulls it into the repo.원본이 하나라서 발표 날 판이 어긋나지 않는다.One source of truth, so two versions never disagree on the day.
    BB 저장소 파일B Repo files를 쓰는 사람People who use git저장소와 로컬 사본은 바뀐다. 온라인 덱은 소유자가 Claude에게 올려 달라고 해야 바뀐다.The repo and local copy change. The online deck changes only when the owner asks Claude to publish the files.글과 노트가 변경 기록과 함께 남는다.Text and notes are kept with a change history.
    CC 파워포인트 파일C PowerPoint file (PPTX)연습이나 최종 동결Personal rehearsal or a final freeze아니다. 별도 사본이라 돌아오지 않는다.No. It is a separate copy and does not flow back.돌아오지 않는 사본을 팀 판으로 쓰면 고친 내용이 사라진다.A copy that does not flow back loses edits if the team treats it as the real deck.
    방법 AWay A

    온라인 덱에서 고친다Edit in the online deck

    왜: 모두가 한 덱을 고치면 합칠 일이 없다. 팀원은 을 몰라도 된다.Why: When all of us edit one deck, nothing needs merging. A teammate needs no git.

    1. 소유자가 덱 화면의 Share 메뉴에서 팀원에게 편집 권한을 준다. 링크만으로는 보기만 된다.The owner gives each teammate edit access from the deck page's Share menu. The link alone allows viewing only.
    2. 팀원이 링크를 열고, 자기 슬라이드의 글을 직접 고친다. 고치기 어렵다면 댓글을 남긴다.Each teammate opens the link and edits the text on their own slides. If unsure, leave a comment.
    3. 변경은 새 버전으로 저장된다.Changes save as new versions.
    4. 소유자가 Claude에게 덱을 저장소로 가져오고 로컬 사본을 다시 만들라고 시킨다.The owner asks Claude to pull the deck into the repo and rebuild the local copy.
    링크가 있는 사람은 누구나 덱을 볼 수 있다. 편집 권한은 소유자가 Share 메뉴에서 준다. 편집하려면 먼저 소유자에게 부탁한다.Anyone with the link can view the deck. Edit access is given by the owner from the Share menu. Ask the owner first if you want to edit.
    방법 BWay B

    저장소 파일에서 고친다Edit the repo files

    왜: 파일로 고치면 변경 기록이 남는다. 슬라이드 한 장이 파일 하나라서 고칠 곳을 찾기 쉽다.Why: Editing files leaves a change history. One slide is one file, so the place to edit is easy to find.

    #할 일Do무엇을 고치나What it changes
    1슬라이드 글을 고친다.Edit slide text.
    tips/presentation/deck/project/slides/<id>.html    		한 파일에 <section> 하나가 있다. 보이는 글은 <h2>, <p>, 표 칸에 둔다. 는 마지막 <aside>에 둔다. 그림 주소(/_blob/...)는 그대로 둔다.One file holds one <section>. Visible text sits in <h2>, <p> and table cells. Speaker notes sit in the last <aside>. Leave the image addresses (/_blob/...) as they are.
    2공통 모양을 고친다.Edit the shared look.
    tips/presentation/deck/project/deck.css    		모든 슬라이드가 쓴다. 글꼴 IBM Plex Mono, 무채색, 각진 모서리다. Q1은 주황, Q2는 청록, Q3는 초록이다. 고치기 전에 묻는다.Every slide uses it. Font IBM Plex Mono, achromatic, square corners. Q1 is orange, Q2 teal, Q3 green. Ask before you edit.
    3순서와 제목을 고친다.Edit order and title.
    tips/presentation/deck/project/deck.json    		제목, 슬라이드 순서("order"), 구간, 글꼴이 있다.It holds the title, the slide order ("order"), the sections and the font.
    4로컬 사본을 다시 만든다.Rebuild the local copy.
    bash tips/presentation/build_local.sh    		slides_local.html과 slides_local.pdf를 새로 쓴다. PDF에는 Chrome이 필요하다. 없으면 HTML만 새로 쓴다.It rewrites slides_local.html and slides_local.pdf. The PDF needs Chrome. Without Chrome only the HTML is rewritten.
    5결과를 확인한다.Check the result.
    tips/presentation/slides_local.html    		브라우저로 열어 고친 슬라이드와 노트를 본다.Open it in a browser and look at the edited slide and its notes.
    6커밋한다.Commit.파일 변경을 으로 남긴다.Record the file changes as a commit.
    이 방법은 온라인 덱을 바꾸지 않는다. 온라인 덱에도 반영하려면 소유자가 Claude에게 파일을 올려 달라고 한다.This way does not change the online deck. To update it too, the owner asks Claude to publish the files.
    방법 CWay C

    파워포인트 파일로 연습한다Rehearse with a PPTX file

    왜: 인터넷 없이 연습하고 싶을 때 쓴다. 원본에는 영향이 없다.Why: Use it to rehearse without internet. The real deck stays untouched.

    1. 온라인 덱 화면에서 이나 PDF로 내려받는다.Download the deck as a PowerPoint file (PPTX) or a PDF from the deck page.
    2. PowerPoint나 Google Slides에서 연다. 고친 파일은 별도 사본이다.Open it in PowerPoint or Google Slides. The edited file is a separate copy.
    3. 고친 내용을 팀 덱에 쓰려면 온라인 덱이나 슬라이드 파일에 손으로 옮긴다.To keep an edit in the team deck, retype it into the online deck or the slide file.
    개인 연습이나 마지막 동결에만 쓴다. 이 사본은 온라인 덱과 저장소로 돌아오지 않는다.Use it only for personal rehearsal or a final freeze. This copy never flows back to the online deck or the repo.

    함께 쓰는 규칙 네 가지Four rules for working together

    왜: 규칙이 적을수록 지키기 쉽다. 넷만 지키면 판이 어긋나지 않는다.Why: Fewer rules are easier to keep. Follow these four and the versions stay together.

    #규칙Rule왜Why
    1자기 슬라이드만 고친다.Edit only your own slides.남의 글을 모르고 바꾸는 일을 막는다.It stops you from changing someone else's text by mistake.
    2같은 슬라이드를 동시에 고치지 않는다.Do not edit the same slide at the same time.두 고침이 서로를 덮어쓸 수 있다.Two edits can overwrite each other.
    3숫자는 논문에서 온다. 논문이 바뀔 때만 숫자를 바꾼다.Numbers come from the paper. Change a number only if the paper changes.출처는 papers/paper_mvp1/numbers.tex다. 논문과 다른 숫자는 발표의 신뢰를 깎는다.The source is papers/paper_mvp1/numbers.tex. A number that differs from the paper hurts trust in the talk.
    4deck.css를 고치기 전에 묻는다.Ask before you change deck.css.모든 슬라이드의 모양이 한 번에 바뀐다.It changes the look of every slide at once.
