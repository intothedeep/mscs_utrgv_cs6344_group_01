  1. 결과를 보기 전에 기준을 고정했다 (D-005, D-007).We fixed the criteria before we saw any result (D-005, D-007).
  2. 모든 숫자는 저장된 run 파일에서 나온다 (D-011, D-014).Every number comes from a saved run file (D-011, D-014).

  4. 방법은 강의 안에서만 쓴다 (D-025, D-026).We use only methods taught in the lecture (D-025, D-026).
  5. 본문은 핵심만 보이고 상세는 부록 A에서 G에 둔다. 본문은 2단이다 (D-042, D-043, D-045).The body shows the core and Appendices A to G hold the details. The body uses two columns (D-042, D-043, D-045).
