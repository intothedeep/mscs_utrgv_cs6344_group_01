    • χ²: 여러 칸의 차이를 한 숫자로 합친다. 합치기 전에 제곱하므로 값은 항상 0 이상이고, 오른쪽 꼬리가 길다.Chi-square: it adds the differences of many cells into one number. Each difference is squared first, so the value is never below 0 and the right tail is long.

    3.1 p값은 이렇게 구한다3.1 How the p-value is computed

    p값은 "가격이 맞다면, 지금만큼 또는 그보다 더 이상한 결과가 우연히 나올 확률"이다. 코드는 한 줄이다: scipy.stats.binomtest(k, n, p). k는 결과 1 개수, n은 시장 수, p는 평균 가격이다. 양쪽 검정이다.The p-value is the chance, if the price is right, of a result this odd or odder. The code is one line: scipy.stats.binomtest(k, n, p), with k the outcome-1 count, n the market count and p the mean price. It is two-sided.

    1. 구간의 n과 평균 가격 p̄로 이항분포 B(n, p̄)를 만든다.Build the binomial B(n, p̄) from the bin's n and mean price.
    2. 관측값 k가 나올 확률 P(X = k)를 구한다.Compute P(X = k), the chance of the observed k.
    3. 왼쪽 꼬리: P(X ≤ k)를 더한다. 기대보다 적게 나온 쪽이다.Left tail: add P(X ≤ k), the side below the expected count.
    4. 오른쪽 꼬리: 기대보다 많은 쪽에서, 확률이 P(X = k) 이하인 값을 모두 더한다. 반대 방향으로 똑같이 드문 결과다.Right tail: on the side above the expected count, add every value whose probability is at most P(X = k). These are equally rare results in the other direction.
    5. p = 왼쪽 꼬리 + 오른쪽 꼬리.p = left tail + right tail.
