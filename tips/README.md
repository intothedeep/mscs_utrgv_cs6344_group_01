# Tips

Explainer pages for the group project. Each page holds English and Korean. Click 한국어 / English to switch.

- Start at `index.html`. It shows every page in tabs.
- Add `?lang=en` to a page URL to open it in English.
- Each page shows the current paper and project. The proposal page is the one exception. It keeps the proposal as posted on 2026-10-18 (D-044).
