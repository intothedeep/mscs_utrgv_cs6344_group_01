\textbf{Question.} Is a Polymarket price a calibrated probability?
We also ask who trades (Q2) and what the trades look like (Q3).

\hd{1. Data and method}
We use the Polymarket-v1 database, which holds \PaperTrades{} trades and \PaperMarkets{} markets from \PaperPeriod{} \citep{qin2026polymarketv1}.
Of \NMarketsInScope{} Yes/No markets in scope we keep \NMarketsKept{} (\PctMarketsKept).
We read each market's price \DaysShort{} day before its scheduled close, because a price after the close can contain the answer.
We drop prices older than \MaxStaleHours{} hours and markets with fewer than \MinTrades{} trades.
We cut the price into \NBins{} equal-width bins.
We test each bin with a binomial test (Benjamini-Hochberg corrected \citep{benjamini1995controlling}) and all bins with a chi-square test.
We fixed the criteria in a pre-registration before any Q1 result.
We report one later rule change as an amendment (tie rule for the price).

\hd{4. Limitations}
\textbf{Independence.} Markets on one event move together, so the p-values may be too small. No event key exists, so we size this only with proxy keys.
\textbf{Selection.} Only \PctMarketsKept{} of markets pass the filters. Kept markets trade more than dropped ones.
